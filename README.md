# ⚽ Football Betting Market Analysis Using SQL

## Overview

This project builds upon a machine learning model developed to estimate football match outcome probabilities and generate betting odds for the **Slovenian First Football League**. Using PostgreSQL, the generated odds are compared with bookmaker odds from **1XBet** and **William Hill** to evaluate betting value, bookmaker margins, and the profitability of different betting strategies.

The project demonstrates how SQL can be used not only for data management, but also for advanced analytical tasks including probability calculations, market comparison, profitability simulations, window function analysis, and the creation of reusable analytical views.

The resulting datasets were later used as the data source for an interactive Tableau dashboard. <br>
<br>

## Project Objectives

The primary objectives of this project were to:

* Transform and organize betting market data into an analytical database.
* Compare machine learning generated odds with bookmaker odds.
* Calculate implied probabilities and bookmaker margins.
* Identify potential value betting opportunities.
* Simulate multiple betting strategies using different selection criteria.
* Evaluate betting profitability using SQL.
* Create reusable analytical views for reporting and visualization.
<br>

## Dataset

The analysis uses betting odds generated by a machine learning model together with market odds collected from **1XBet** and **William Hill** for matches in the **Slovenian First Football League**.

The database contains three betting markets:

* Home Win
* Draw
* Away Win

Each market contains:

* Generated betting odds
* Bookmaker odds
* Match information
* Match outcomes
* Season and matchday information

The project combines these datasets into a unified betting market for further analysis.

## Analysis Workflow

The SQL project is organised into six analytical phases.

### Phase 1 – Data Preparation & Exploration

* Explore imported betting datasets.
* Verify data quality and completeness.
* Identify missing values and inconsistencies.
* Correct detected data issues.
* Prepare supporting tables for analysis.

### Phase 2 – Probability & Value Betting Analysis

* Convert decimal odds into implied probabilities.
* Compare generated probabilities with bookmaker probabilities.
* Calculate betting edge.
* Identify value betting opportunities.
* Simulate profitability using different edge thresholds.

### Phase 3 – Betting Strategy Evaluation

Different betting strategies were evaluated, including:

* Betting every identified value opportunity.
* Selecting only the highest-edge bets.
* Limiting bets to the Top-N ranked opportunities.
* Selecting the best betting opportunity per matchday.

Each strategy was evaluated using simulated betting profits.

### Phase 4 – Market Integration & Bookmaker Analysis

The three betting markets were combined into a unified analytical dataset.

Additional analyses included:

* Bookmaker margin calculation.
* Market probability comparison.
* Odds disagreement analysis.
* Ranking the largest pricing differences between bookmakers and generated odds.

### Phase 5 – Advanced SQL Analytics

Advanced SQL functionality was applied to demonstrate analytical querying techniques, including:

* Window Functions
* Ranking Functions
* LAG() and LEAD()
* Common Table Expressions (CTEs)
* Temporal odds movement analysis

### Phase 6 – Analytical Views

The final stage creates reusable SQL views that consolidate the analysis into reporting-ready datasets.

The repository includes:

* **final_betting_analysis** – comprehensive comparison between generated and bookmaker odds.
* **betting_returns** – simulated betting performance including normalized probabilities, betting edge, and profit calculations.

These views were designed as the primary data source for the accompanying Tableau dashboard.

## Key Findings

The SQL analysis demonstrated that:

* Machine learning generated odds can be systematically compared with bookmaker markets using SQL.
* Bookmaker margins can be quantified and incorporated into betting analysis.
* Betting edge provides a useful criterion for identifying potential value bets.
* Different betting strategies produce substantially different profitability outcomes.
* SQL is capable of supporting an entire analytical workflow beyond traditional database management.
